## 2. Strategic Placement in Pipeline

Pseudo-labeling's position in the pipeline determines how much the downstream model benefits:

```
Phase 1:     200 ep baseline ───→ best checkpoint
                   │
Phase 2a:    P3 scratch training ───→ small-face detection enabled
                   │
Phase 2b:    ATSS dynamic assignment ───→ better positive cell allocation
                   │
          ╔══════════════════════════════════════════╗
          ║  Phase 3: PSEUDO-LABELING (3 cycles)    ║
          ║  ← Pseudo-labels generated by strongest  ║
          ║    model (P3+ATSS), feeds back to train  ║
          ║    on 2.3× data with self-correction     ║
          ╚══════════════════════════════════════════╝
                   │
Phase 4:    All inference optimizations (WBF, TTA, calibration...)
                   │
Final:      mAP evaluation
```

Pseudo-labeling must come BEFORE inference-only optimizations (Phase 4) because it changes model weights. Any inference trick applied first would need re-tuning after the model changes.

## 3. Expansion 1: Noisy Student Training

### 3.1 Concept

The baseline pseudo-labeling fine-tunes the same model on its own predictions — the model can never exceed the teacher because it's the same architecture with the same augmentations. Noisy Student Training (Xie et al., NeurIPS 2020) breaks this ceiling:

1. **Teacher** model generates pseudo-labels on unlabeled data
2. **Student** model (same architecture) trains to predict pseudo-labels with **stronger augmentation** than the teacher saw
3. Student becomes better than teacher → becomes the new teacher → repeat

**Why it works:** The student must learn to predict the same detections under harder conditions (RandAugment, random erasing, dropout, stochastic depth). To match the teacher's output with corrupted inputs, the student must learn more robust features. These robust features generalize better — the student excels where the teacher's overfitted features fail.

### 3.2 Implementation

```python
# ── Teacher generates pseudo-labels ──
teacher = load_checkpoint("face_cnn_v7_best.pth")
teacher.eval()
pseudo_labels = {}
for img in unlabeled_loader:
    dets = teacher.detect(img, quality_threshold=0.3)
    pseudo_labels[img] = dets  # (x, y, w, h, quality)

# ── Student trains with strong augmentation ──
student = FaceFCNv7()
student.load_state_dict(teacher.state_dict())  # same init

# Student augmentations (stronger than teacher's training):
student_augment = transforms.Compose([
    transforms.HorizontalFlip(),
    transforms.RandAugment(N=2, M=9),     # 2 ops, magnitude 9
    transforms.RandomErasing(p=0.2),       # 20% random erasing
    transforms.ColorJitter(0.3, 0.3, 0.2), # stronger color jitter
])

# Training: labeled data (BCE loss) + pseudo data (student-teacher KL)
for batch in mixed_loader:
    labeled_imgs, gt_targets = labeled_batch
    pseudo_imgs, pseudo_targets = pseudo_batch
    
    # Student forward with strong aug on pseudo images
    student_out = student(student_augment(pseudo_imgs))
    pseudo_loss = KL_divergence(student_out, pseudo_targets)  # softened targets
    
    # Normal BCE loss on labeled data
    labeled_out = student(labeled_imgs)
    labeled_loss = BCE(labeled_out, gt_targets)
    
    total_loss = labeled_loss + pseudo_loss * 0.5  # balance weights
    
    total_loss.backward()
    optimizer.step()
```

### 3.3 Key Parameters

| Parameter | Baseline pseudo | Noisy Student | Rationale |
|---|---|---|---|
| Student augmentation | Same as teacher | **RandAugment N=2, M=9 + RandomErasing** | Forces robustness |
| Pseudo loss | BCE (hard targets) | **KL divergence (soft targets)** | Preserves teacher uncertainty |
| Labeled vs pseudo weight | 1:1 in batch | **1:1 in batch** (Xie default) | Unchanged |
| Iterations | 1 | **2** (student→teacher→student) | Each iteration compounds gains |
| Epochs per iteration | 25 | **50** (harder aug needs more ep) | Converges slower with strong aug |
| EMA | During training | **Same** | Unchanged |
| Mining | Active | **Active** | Same self-correction |

### 3.4 Expected Behavior

| Iteration | Teacher → Student | Expected gain over previous |
|---|---|---|
| 1 | Phase 1 best → student (strong aug) | +0.02-0.03 mAP |
| 2 | Iter 1 student → new student | +0.01-0.02 mAP (diminishing) |
| **Total vs baseline pseudo** | | **+0.03-0.05 mAP** |

### 3.5 Cost

| Component | Time | Notes |
|---|---|---|
| Teacher inference on 16K images | ~8 min | Same as baseline |
| Student training (50 ep × 306s) | **4.3h** | 2× baseline per cycle (harder aug) |
| Iteration 2 (re-label + train) | **4.3h** | Second pass |
| **Total Noisy Student** | **~8.6h** | vs 5.2h baseline |

### 3.6 Trade-offs

| Pro | Con |
|---|---|
| Proven technique (NeurIPS 2020) — +0.5-1.0% on ImageNet | +3.4h over baseline pseudo |
| Student consistently exceeds teacher | Diminishing returns on iteration 2 |
| No extra data needed | RandAugment hyperparameter tuning |
| Compatible with cross-dataset expansion | Higher VRAM (stronger aug = more compute) |

## 4. Expansion 2: Re-Label WIDER Training Set

### 4.1 Problem

WIDER Face ground truth annotations are **incomplete**. From the dataset documentation:

> "WIDER Face contains 32,203 images with 393,703 labeled faces. However, many faces are unlabeled, particularly small faces (<20px), heavily occluded faces, and faces at image boundaries."

Estimates from published analyses suggest **15-20% of faces are missing** from the training annotations. This means the model is penalized for detecting a face that exists but isn't labeled — the loss treats it as a false positive, teaching the model to ignore real faces.

### 4.2 Method

1. Run trained model on all 12,880 **training** images (not test images)
2. Collect all detections with quality > 0.4 that do NOT overlap any existing GT box (IoU < 0.1)
3. These "extra" detections are likely true unlabeled faces
4. Add them as pseudo-labels to the training set with smoothing s=0.2
5. Train from the best checkpoint on the corrected set

```python
for img, gt_boxes in train_dataset:
    detections = model.detect(img, quality_threshold=0.4)
    for det in detections:
        overlaps = [compute_iou(det.bbox, gt) for gt in gt_boxes]
        if max(overlaps) < 0.1:  # no overlap with existing GT
            pseudo_labels.append({
                "image": img,
                "bbox": det.bbox,
                "quality": det.quality,
                "source": "relabeled"
            })
```

### 4.3 Filtering Strategy

| Parameter | Value | Reason |
|---|---|---|
| Quality threshold | 0.4 (vs 0.3 for test images) | Training set has GT — higher bar prevents adding noise |
| IoU overlap max | < 0.1 | Must not duplicate existing annotation |
| Expected new faces | **~60-80K** (15-20% of 393K) | From 15-20% missing rate |

### 4.4 Training After Re-Labeling

The training set grows from 12,880 → 12,880 images (same count, but each training image may have 1-4 additional face annotations). The model gets gradient from previously unlabeled faces.

**Training config:**
- Same as Phase 1 Max (multi-scale, copy-paste, mining, SGDR×3)
- 50 epochs from best checkpoint
- Mining threshold lowered: any detection on corrected training images with quality > 0.3 that overlaps a **re-labeled** face is explicitly treated as a **false positive** — this prevents the model from learning to ignore the re-labeled annotations

### 4.5 Cost

| Component | Time |
|---|---|
| Inference on 12,880 training images | ~6 min (batch) |
| Filtering + merging pseudo-labels | ~1h dev |
| Training (50 ep × 306s) | **4.3h** |
| **Total** | **~5.5h** |

### 4.6 Expected Impact: +0.01-0.02 mAP

Re-labeling helps **primarily at the margins** — the added faces are mostly small, occluded, or boundary cases. These improve recall on the Hard subset of WIDER Face but have minimal impact on Easy/Medium. This is a **complementary** strategy to pseudo-labeling on test images — they fix different data gaps.

## 5. Expansion 3: Cross-Dataset Pseudo-Labeling

### 5.1 Concept

The model is trained exclusively on WIDER Face (61 event classes, mostly unconstrained outdoor scenes). Face appearance, occlusion patterns, and lighting vary across datasets. Adding pseudo-labels from other face datasets exposes the model to broader distributions with zero manual labeling cost.

### 5.2 Candidate Datasets

| Dataset | Images | Domain | License | Download |
|---|---|---|---|---|
| **FDDB** | 2,845 | Unconstrained faces in the wild | Research | Public |
| **MAFA** | **30,811** | **Occluded faces** (masks, hands, glasses, phones) | Research | Public |
| **UFDD** | 6,425 | Challenging conditions (rain, fog, snow, blur, lens flare) | Research | Public |
| **WIDER FACE test** | 16,103 | Same distribution as training (already in baseline) | Research | Included |
| **Total added** | **~40K** | | | |

**MAFA (Masked Face) is the highest-value addition.** It specifically addresses occlusion — faces partially covered by masks, hands, phones, glasses, and other objects. For real-world gimbal deployment, occlusion is the primary failure mode (a subject's hand over their face, sunglasses, turning away). Training on WIDER alone provides limited occlusion robustness; MAFA directly fills this gap.

### 5.3 Inference Pipeline

```python
def pseudo_label_dataset(model, dataset_path, quality_threshold=0.3):
    pseudo_results = []
    for img_path in tqdm(os.listdir(dataset_path)):
        img = cv2.imread(img_path)
        dets = model.detect(img, quality_threshold=quality_threshold)
        for d in dets:
            pseudo_results.append({
                "image": img_path,
                "bbox": (d.x, d.y, d.w, d.h),
                "quality": d.quality,
                "dataset": os.path.basename(dataset_path),
            })
    return pseudo_results
```

### 5.4 Filtering & Quality Control

Cross-dataset pseudo-labels are inherently noisier than same-distribution ones (MAFA's occluded faces look different from WIDER's full faces). Apply stricter filtering:

| Parameter | WIDER test pseudo | Cross-dataset pseudo |
|---|---|---|
| Quality threshold | > 0.3 | **> 0.4** (stricter) |
| Label smoothing | s=0.2 | **s=0.3** (more noise-tolerant) |
| Loss weight | 1.0 | **0.5** (lower weight for out-of-distribution) |

### 5.5 Training

Same structure as Phase 2 but with mixed sources:

```python
train_dataset = WIDER_labeled(12,880)  # original GT
pseudo_wider = WIDER_pseudo(16,000)    # WIDER test pseudo
pseudo_mafa = MAFA_pseudo(30,811)      # cross-dataset pseudo
pseudo_fddb = FDDB_pseudo(2,845)       # cross-dataset pseudo
pseudo_ufdd = UFDD_pseudo(6,425)       # cross-dataset pseudo

# Cross-dataset samples get lower loss weight
for batch in DataLoader(train_dataset + pseudo_datasets):
    loss = labeled_loss + pseudo_wider_loss + 0.5 * (mafa + fddb + ufdd)
```

### 5.6 Cost

| Component | Time |
|---|---|
| Download + prepare datasets (MAFA, FDDB, UFDD) | ~2h (download) |
| Inference on ~40K images at 30ms/img | ~20 min |
| Training (50 ep × 306s) | **4.3h** |
| **Total** | **~6.5h** |

### 5.7 Expected Impact: +0.03-0.05 mAP

Cross-domain exposure provides the largest gain of any pseudo expansion because it addresses the model's fundamental blind spots (occlusion, adverse conditions) rather than just providing more examples of the same distribution. The MAFA occluded-face data alone is worth +0.02-0.03 mAP on the Hard WIDER subset.

## 6. Expansion 4: Confidence-Based Curriculum

### 6.1 Concept

The baseline pseudo-labeling adds all detections above a fixed threshold (quality > 0.3) simultaneously. But not all pseudo-labels are equally reliable — high-confidence detections (quality > 0.7) are nearly as good as ground truth, while marginal ones (quality ~0.3) are noisy.

A curriculum strategy adds pseudo-labels in order of confidence:

```
Epochs 1-5:   Only quality > 0.7  (high confidence, low noise)
Epochs 6-10:  Add quality > 0.5   (medium confidence)
Epochs 11-15: Add quality > 0.3   (low confidence, full set)
```

**Why it helps:** The model first learns from the cleanest pseudo-labels, establishing solid feature baselines. Later, when lower-quality pseudo-labels are added, the model has already learned reliable detection patterns — it can use the noisy samples for fine-tuning without being destabilized. This is the same curriculum principle used in self-training for NLP (Clark et al., 2018).

### 6.2 Implementation

```python
class CurriculumPseudoDataset(Dataset):
    def __init__(self, pseudo_data, epoch_schedule):
        self.pseudo_data = pseudo_data
        self.schedule = epoch_schedule
        
    def set_epoch(self, epoch):
        # Determine quality threshold for this epoch
        if epoch < 5:
            self.active_threshold = 0.7
        elif epoch < 10:
            self.active_threshold = 0.5
        else:
            self.active_threshold = 0.3
            
    def __getitem__(self, idx):
        # Only return samples above current threshold
        sample = self.pseudo_data[idx]
        if sample.quality < self.active_threshold:
            return None  # skip this sample
        return sample
```

### 6.3 Cost

**Zero additional compute.** The same pseudo-labels are used — they're just phased in. Implementation is ~20 lines of code.

### 6.4 Expected Impact: +0.01-0.02 mAP over flat threshold

Curriculum provides a regularization benefit during fine-tuning, not new data. The gain comes from faster convergence (clean data first) and better ultimate precision (the model isn't confused by early exposure to noisy samples).

## 7. Expansion 5: Self-Training with Consistency Regularization

### 7.1 Concept

Consistency regularization (also called \(\Pi\)-model or Mean Teacher) adds a loss term that penalizes the model when its predictions differ between two augmentations of the same input:

```python
loss = supervised_loss + λ * ||f(aug1(x)) - f(aug2(x))||²
```

For pseudo-labeling, this means: for each unlabeled image, run it through the model with two different random augmentations. The model should produce the same detections regardless of augmentation. If it doesn't, the consistency loss pushes it to be augmentation-invariant.

**Why it helps:** The pseudo-labels from the teacher are static (generated once per cycle). Consistency regularization allows the unlabeled data to provide a **dynamic** training signal that updates every batch. The model isn't just memorizing pseudo-labels — it's learning to produce consistent detections under all transformations.

### 7.2 Implementation

```python
# For each unlabeled image in batch:
x1 = student_augmentation(image)  # strong aug version 1
x2 = student_augmentation(image)  # strong aug version 2

out1 = student(x1)
out2 = student(x2)

# Teacher pseudo-label (static, generated once per cycle)
pseudo_target = teacher_pseudo_labels[image_idx]

# Three losses:
L_sup = BCE(student(labeled_img), gt)                     # supervised
L_pseudo = KL(student(x1), pseudo_target)                   # pseudo-label fit
L_consist = MSE(out1["p4_obj"], out2["p4_obj"])            # consistency

loss = L_sup + 0.5 * L_pseudo + 0.1 * L_consist
```

### 7.3 Cost

| Component | Time |
|---|---|
| Forward pass | 2× per unlabeled image (two augmentations) |
| Backward pass | 1× (shared computation graph) |
| Overhead | **+50-70%** per epoch during pseudo-labeling |
| **Total** | ~7-9h for 25-ep cycle (vs 4.3h baseline) |

### 7.4 Expected Impact: +0.02-0.03 mAP over baseline pseudo

Consistency regularization is well-studied in semi-supervised learning. For object detection, the effect is moderate because detection features are already somewhat augmentation-invariant (copy-paste + multi-scale training in Phase 1 provide strong invariance). The gain comes primarily from improved calibration on unlabeled data.

## 10. Implementation Notes

### 10.1 Infrastructure for Cross-Dataset Pseudo-Labeling

```python
# Unified pseudo-label dataset format
@dataclass
class PseudoLabel:
    image_path: str
    bbox: Tuple[int, int, int, int]  # x, y, w, h
    quality: float
    source: str  # "wider_test", "mafa", "fddb", "ufdd", "relabeled"
    label_smoothing: float = 0.2  # per-source noise estimate
    
class MixedPseudoDataset(Dataset):
    """Combines labeled WIDER + multiple pseudo-label sources.
    Each source can have its own loss weight and noise level."""
    def __init__(self, labeled, pseudo_sources):
        self.labeled = labeled
        self.pseudo = pseudo_sources  # list of (dataset, weight, smoothing)
    
    def __getitem__(self, idx):
        if idx < len(self.labeled):
            return self._get_labeled(idx)
        return self._get_pseudo(idx - len(self.labeled))
```

### 10.2 Quality Score Inflation Warning

When the same model generates pseudo-labels and trains on them, the quality scores can **inflate** — the model becomes overconfident on easy examples because it keeps seeing its own confident predictions. Mitigation strategies in order of effectiveness:

1. **Different augmentations for teacher vs student** (Noisy Student approach) — best
2. **Label smoothing** (s=0.2-0.3 for pseudo-labels) — already in baseline
3. **Quality score as training weight** (down-weight low-quality pseudo-labels in the loss)
4. **Random pseudo-label dropout** (randomly discard 10% of pseudo-labels each batch)

### 10.3 Data Balance

When adding cross-dataset pseudo-labels, per-dataset class imbalance can shift the model's priors. MAFA has ~30K images with partially occluded faces — if weighted equally with WIDER (12.9K), the model learns occlusion bias. Mitigation:

```python
# Per-dataset sampling weights
source_weights = {
    "wider_labeled": 1.0,      # anchor
    "wider_pseudo": 1.0,       # same distribution
    "mafa_pseudo": 0.5,        # occluded domain, don't overfit
    "fddb_pseudo": 1.0,        # wild domain, similar to WIDER
    "ufdd_pseudo": 0.3,        # adverse conditions, niche
    "relabeled": 1.0,          # same as GT
}
```

### 10.4 Checkpoint Strategy During Expansions

Each expansion produces a checkpoint that feeds the next. Document the lineage:

```
face_cnn_v7.pth (Phase 1 best, P4 F1=0.611)
  └─ face_cnn_v7_p3ft.pth (P3 scratch training)
      └─ face_cnn_v7_atss.pth (ATSS dynamic assignment)
          └─ face_cnn_v7_pseudo.pth (Phase 2: 3 cycles, best checkpoint)
              └─ face_cnn_v7_relabel.pth (Re-label WIDER training)
                  └─ face_cnn_v7_mafa.pth (Cross-dataset MAFA)
                      └─ face_cnn_v7_noisy.pth (Noisy Student iteration 1)
                          └─ face_cnn_v7_final.pth (Noisy Student iteration 2)
```

All intermediate checkpoints are archived. If any expansion degrades mAP (possible with noisy cross-domain data), roll back to the previous checkpoint.
